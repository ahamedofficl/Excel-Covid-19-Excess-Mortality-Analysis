# COVID-19 Excess Mortality Analysis 📊

## Overview
This Excel project analyzes the excess mortality rates during the COVID-19 pandemic to understand the true impact of the virus compared to historical baseline mortality data.

## Key Features & Tools Used
- **Data Cleaning & Preparation:** Handled missing values, standardized country/regional data.
- **Formulas & Functions:** Used `VLOOKUP`, `INDEX/MATCH`, `SUMIFS`, `AVERAGEIFS`, and Percentage Growth calculations.
- **Data Aggregation:** Created **Pivot Tables** to analyze mortality trends by year, region, and age groups.
- **Visualization:** Built interactive **Excel Dashboards** using slicers, trend lines, and bar charts.

## Key Insights
- Comparison between reported COVID-19 deaths vs. expected baseline deaths (Excess Mortality).
- Key spikes and trends identified during specific wave periods.
